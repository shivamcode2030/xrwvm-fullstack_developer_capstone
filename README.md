# Car Dealership Full-Stack Application

## Project Description
A full-stack car dealership application built using Django, React, and REST APIs.

The application allows users to:
- View car dealerships
- Search and filter dealerships by state
- View dealer details and reviews
- Register and log in
- Submit dealership reviews
- View car makes and models
- Analyze review sentiment

## Technologies Used
- Django
- React
- Python
- JavaScript
- SQLite
- REST APIs
- GitHub Actions

## Project Structure
- `server/` - Django backend and application APIs
- `server/frontend/` - Frontend pages and React components
- `.github/workflows/` - CI/CD configuration
